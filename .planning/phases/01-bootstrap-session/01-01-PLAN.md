# Plan 01-01: Project Scaffold, Config, Telethon Wrapper, Login Script

**Phase:** 1 — Bootstrap & Session
**Status:** Ready to execute
**Plans in phase:** 1 (this is the only plan for Phase 1)

## Goal

Create a clean Python package with typed env-driven config, a Telethon client wrapper, and a one-shot interactive login script — enough to prove "we can log into Telegram and print who we are" without any event handling yet.

## Tasks (atomic commits, executed in this order)

### Task 1: Repo skeleton + `.gitignore` + `.env.example` + `README.md`
**Commit message:** `chore(01): add repo skeleton and gitignore`

Create:
- `.gitignore` — excludes `.venv/`, `__pycache__/`, `*.session*`, `.env`, `.local/`, build artifacts, ruff/pytest caches
- `.env.example` — placeholder values with comments explaining each
- `README.md` — setup instructions: venv, `pip install -e '.[dev]'`, copy `.env.example` → `.env`, fill values, run `python scripts/login.py`, then `python -m tg_voice_transcriber`

### Task 2: `pyproject.toml` with pinned deps + ruff + pytest config
**Commit message:** `chore(01): add pyproject.toml with pinned deps`

Create `pyproject.toml` using hatchling (standard PEP 517 backend, simple). Pin:
- Runtime: `telethon>=1.43,<2.0`, `pydantic>=2.6,<3.0`, `pydantic-settings>=2.2,<3.0`, `python-dotenv>=1.0,<2.0`, `structlog>=24.1`
- Dev extras: `ruff>=0.5`, `pytest>=8.0`, `pytest-asyncio>=0.23`
- Script entry: `tg-voice-transcriber = "tg_voice_transcriber.__main__:main"` (optional convenience)
- `[tool.ruff]` with sensible rule set (E, F, I, UP, B, W, SIM)
- `[tool.pytest.ini_options]` with `asyncio_mode = "auto"`

### Task 3: Package scaffold — `src/tg_voice_transcriber/__init__.py`, `config.py`, `logging.py`
**Commit message:** `feat(01): add Config and structlog setup`

Create:
- `src/tg_voice_transcriber/__init__.py` with `__version__ = "0.1.0"`
- `src/tg_voice_transcriber/config.py` — `Config(BaseSettings)` class. Fields: `api_id: int`, `api_hash: SecretStr`, `phone: str`, `session_path: Path = Path(".local/userbot.session")`, `log_level: str = "INFO"`. Env prefix `TG_VOICE_`. Use `SettingsConfigDict(env_file=".env", env_prefix="TG_VOICE_", extra="ignore")`. Single `get_config()` cached accessor.
- `src/tg_voice_transcriber/logging.py` — `configure_logging(level: str)` sets up structlog with KeyValueRenderer. No JSON for dev-readability; Phase 5 can switch to JSON.

### Task 4: `client.py` — `TelegramUserbot` wrapper + `SessionInvalidError`
**Commit message:** `feat(01): add TelegramUserbot wrapper with session invalid detection`

Create `src/tg_voice_transcriber/client.py`:
- Custom exception: `class SessionInvalidError(RuntimeError)` with a `reason: str` attribute
- `class TelegramUserbot`:
  - `__init__(self, config: Config)` — stores config, instantiates `TelegramClient(session=str(config.session_path), api_id=config.api_id, api_hash=config.api_hash.get_secret_value())`. Ensures `session_path.parent` exists.
  - `async start(self) -> None` — calls `client.connect()`. If `is_user_authorized()` is False, raises `SessionInvalidError("not_authorized")`. Catches `AuthKeyError`, `UserDeactivatedError` and wraps into `SessionInvalidError(reason=type(e).__name__)`.
  - `async stop(self) -> None` — `await self._client.disconnect()`
  - `async who_am_i(self) -> str` — returns `(await client.get_me()).username or first_name or id`
  - Property `client` exposes the underlying `TelegramClient` for later phases
  - Does NOT register any event handlers

### Task 5: `__main__.py` — greeter that connects, prints identity, idles
**Commit message:** `feat(01): add __main__ entry that logs in and idles`

Create `src/tg_voice_transcriber/__main__.py`:
- `async def main() -> None`: load config, configure logging, construct `TelegramUserbot`, call `start()`, log `connected as @{who_am_i}`, then `await userbot.client.run_until_disconnected()`.
- On `SessionInvalidError`: log `AUTH_REQUIRED reason={reason} — run scripts/login.py on your local machine`, exit non-zero (exit code 78 — `EX_CONFIG`, good match for "config not ready").
- Catch `KeyboardInterrupt` / `asyncio.CancelledError` to run `stop()` cleanly.
- Sync shim `def _sync_main()` uses `asyncio.run(main())`.

### Task 6: `scripts/login.py` — one-shot interactive login
**Commit message:** `feat(01): add interactive login script`

Create `scripts/login.py`:
- Load config
- Build `TelegramClient(session=..., api_id=..., api_hash=...)`
- Call `client.start(phone=cfg.phone)` (Telethon's high-level sync-style helper that prompts stdin for code and 2FA password automatically)
- Print:
  - A short banner `GSD ► one-time Telegram login`
  - Step-by-step reminder: "You'll be asked for the login code Telegram sends to your app/SMS. If 2FA is enabled, your password."
- On success: `print(f"Session saved to: {cfg.session_path.resolve()}")` and `client.disconnect()`.
- On any exception: print error, exit code 1.

## Goal Verification

After the plan executes, a human can:
1. Clone the repo, `pip install -e '.[dev]'` succeeds in a Python 3.11 venv
2. Copy `.env.example` to `.env`, fill in the four values
3. Run `python scripts/login.py`, enter the code, see `Session saved to: .local/userbot.session`
4. Run `python -m tg_voice_transcriber`, see a log line with their Telegram username, Ctrl+C exits cleanly

Success criteria from ROADMAP covered:
- ✅ #1 `pip install -e .` succeeds
- ✅ #2 login.py prompts + creates session file
- ✅ #3 Subsequent run connects without prompt and logs identity
- ✅ #4 Invalid session → non-zero exit with AUTH_REQUIRED log line
- ✅ #5 No secrets in repo (`.env` gitignored, `.env.example` has placeholders)
