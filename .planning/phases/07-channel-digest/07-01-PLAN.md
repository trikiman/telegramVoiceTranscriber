# Plan 07-01: Channel Digest implementation

**Phase:** 7 — Channel Digest (v1.1)
**Status:** Ready to execute

## Goal

Ship a channel digest feature: ingest new channel posts into SQLite, batch-score via Groq LLM every 30 min, format and deliver to a user-configured private channel. Command surface for setup, pause/resume, stats, prefs edits.

## Tasks (atomic commits, in order)

### Task 1: Extract shared GroqClient
**Commit:** `refactor(07): extract shared GroqClient with 6-key rotation`

- New module `src/tg_voice_transcriber/groq_client.py`:
  - `GroqClient` class with 6-key rotation, shared HTTP client
  - Methods: `transcribe_ogg(bytes, language) -> TranscriptResult`, `chat_completion(messages, model, response_format) -> dict`
  - Both methods rotate keys on 429
- Refactor `GroqTranscriber` to thin wrapper around `GroqClient.transcribe_ogg()`
- Update `__main__.py` to construct one `GroqClient`, pass it around
- Confirm existing tests still pass

### Task 2: SQLite schema + migrations
**Commit:** `feat(07): add SQLite schema for digest state`

- New module `src/tg_voice_transcriber/digest/db.py`:
  - `init_db(path: Path) -> None` creates tables if absent
  - Tables: `config`, `tracked_channels`, `post_buffer`, `dedupe_cache`, `stats`
  - Indexes on `(channel_id, received_at)`, `(post_hash)`, etc.
  - Async wrapper using `aiosqlite`
  - Schema version marker for future migrations
- Add `aiosqlite>=0.20,<1.0` to pyproject
- Add `digest_db_path` to Config (default `Path("/var/lib/tg-voice-transcriber/digest.db")` — but use `session_path.parent / "digest.db"` as default for portability)

### Task 3: Digest ingest handler
**Commit:** `feat(07): add channel ingest handler for tracked channels`

- New module `src/tg_voice_transcriber/digest/ingest.py`:
  - `register_digest_handler(client, db, default_track_all: bool)`:
    - Registers a `NewMessage(incoming=True)` handler scoped to channels
    - Filter: `event.is_channel and not event.is_group`
    - Check message text length, skip empty/media-only posts
    - Check `tracked_channels` table; if not present and `default_track_all=True`, auto-add
    - Check `dedupe_cache`: hash first 200 chars, skip if recent duplicate
    - Insert into `post_buffer`
  - Log at INFO with hashed channel_id, post length

### Task 4: LLM scorer + batch processor
**Commit:** `feat(07): add batched Groq LLM scorer`

- New module `src/tg_voice_transcriber/digest/scorer.py`:
  - `DigestScorer(groq_client, model="llama-3.3-70b-versatile")`:
    - `async score_batch(posts: list[Post], user_prefs: str) -> list[ScoredPost]`
    - Build system+user prompt, request JSON mode (`response_format={"type": "json_object"}`)
    - Parse response, validate schema, tolerate minor LLM errors (retry once on non-JSON)
    - Fall back to all-low-score if LLM fails after retry (keeps buffer drained)
  - `@dataclass ScoredPost`: `post_id, channel_id, message_id, score, summary, channel_username`

### Task 5: Digest formatter + delivery
**Commit:** `feat(07): add digest formatter and delivery`

- New module `src/tg_voice_transcriber/digest/formatter.py`:
  - `format_digest(scored_posts: list[ScoredPost], threshold: int, window: Period) -> str | None`
  - Returns None if no posts above threshold (caller skips send)
  - Group by channel, format per the template from CONTEXT.md
  - Include `https://t.me/{channel_username}/{message_id}` links (or `https://t.me/c/{numeric_chat}/msg` for private channels)
  - Clamp total length to 4096 chars (split to multiple messages if larger)

### Task 6: Scheduler (background task)
**Commit:** `feat(07): add digest scheduler background task`

- New module `src/tg_voice_transcriber/digest/scheduler.py`:
  - `DigestScheduler(db, scorer, formatter, reply_service)`:
    - `start()` spawns an asyncio task
    - Loop: sleep until next tick (respects `config.frequency_s`) → if not paused → drain `post_buffer` → score batch → format → send to delivery chat → write stats row
    - Graceful stop: set flag, wait for current cycle to finish
  - Handles empty buffer gracefully (no LLM call, no send)
  - Handles LLM failure gracefully (logs, drops batch, continues next cycle)

### Task 7: Command handlers
**Commit:** `feat(07): add /digest command handlers`

- New module `src/tg_voice_transcriber/digest/commands.py`:
  - `register_command_handlers(client, db, scheduler, userbot)`:
    - Handler for `outgoing=True, pattern=r"^/digest(\s.*)?$"` in self-chat (Saved Messages)
    - Dispatcher: `setup`, `pause`, `resume`, `now`, `channels`, `prefs`, `stats`, `threshold`, `unsub`, `help`
  - `setup` is conversational — uses Telethon's `conversation()` helper to walk through steps
  - Each command edits its own invocation message (no reply spam)

  - New log line at ready: `digest_enabled=true|false`

## Success Verification

1. `systemctl status tg-voice-transcriber` green after deploy
2. Log shows `digest_enabled=false` on first start (no config yet)
3. User runs `/digest setup` in Saved Messages → walks through wizard → config saved
4. User runs `/digest now` → first digest arrives in delivery channel within 30 sec
5. After 30 min, scheduled digest arrives automatically if new posts match
6. Empty-buffer cycle logs "no_posts_in_buffer" without sending a message
7. `/digest stats` after a day shows scanned/delivered counts
8. `/digest pause` stops scheduled deliveries; `/digest resume` restarts them
9. Voice transcription continues working throughout — no regression

## Out of Scope

- Rich media handling (channel voice posts, images)
- Per-channel threshold overrides
- Reaction-based learning
- Export to Notion/etc.
- Multi-user

## Risk & Mitigation

| Risk | Likelihood | Impact | Mitigation |
|---|---|---|---|
| Groq LLM returns non-JSON | Medium | Batch lost | Retry once with stricter prompt, then drop batch (log only) |
| Many channels, large batch > model context | Low-Medium | Batch errors | Chunk batch into sub-batches of max 100 posts if needed |
| User misconfigures delivery channel | Medium | No digests sent | Setup wizard validates bot can post before saving |
| SQLite lock contention with ingest | Low | Dropped posts | Use aiosqlite with WAL mode |
| Daily token quota | Low (6 keys × 1M tokens) | Digest stops | Log warning, emit status; rotation already handles 429 |
