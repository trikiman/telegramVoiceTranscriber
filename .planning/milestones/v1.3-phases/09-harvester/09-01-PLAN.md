# Plan 09-01: Active VPN Bot Harvester

**Phase:** 9 — Active VPN Bot Harvester (v1.3)
**Status:** Executed 2026-07-24

## Goal

Make `scripts/harvest_vpn_bots.py` actually work: actively discover VPN-trial
bots across multiple sources, judge them with the existing `OfferJudge`, and file
qualifying bots into the target folder until 5 are collected, guaranteeing at
least one 30-day trial. Fix every bug that made prior runs return nothing.

## Context: why prior runs produced zero results

Root-cause audit (2026-07-24) found the harvester could not run at all:

1. **Import crash** — `harvest_vpn_bots.py` imported `create_chat_client` from
   `llm_failover`, which did not exist → `ImportError` on startup.
2. **Wrong folder name** — hard-coded `"10 дней vpn"` (Cyrillic) never matched
   the user's renamed `"10+ days vpn"` folder, and matching was exact +
   case-sensitive, so any rename broke it.
3. **Folder clobber** — the folder was resolved once and reused; each
   `add_peer_to_folder` rebuilt `include_peers` from a stale list, so adding a
   2nd bot in one run erased the 1st.
4. **Hang risk** — `client.start(phone=...)` could block on an interactive code
   prompt for an unauthorized session.
5. **No flood/So no ban safety** — no `FloodWaitError` handling or /start cap.
6. **Single narrow source** — only `iter_messages(None, search=...)` global
   search, which is not a web-wide index and returns little unless the account
   follows VPN channels.

REQUIREMENTS.md had HARVEST-01..04 marked `[x] Satisfied` despite all of the
above — the boxes were checked without a live run. Reset in this phase.

## Out of Scope

- Auto-joining discovered channels (use `discover-channels.py` +
  `subscribe-channels.py`).
- /start-probing bots found only by username with no offer text (use
  `probe-bots.py`).
- Any change to the voice-transcription or digest subsystems.

## Risk & Mitigation

| Risk | Likelihood | Impact | Mitigation |
|---|---|---|---|
| Global search returns little (not web-wide) | High | Few candidates | Channel-feed + sponsored sources; prompt to subscribe to VPN channels |
| Sponsored API empty for userbot | High | Source yields nothing | Treated as best-effort supplement, never the sole source |
| FloodWait from active scanning | Medium | Ban risk | Circuit-breaker + /start budget + human-like delays |
| No 30-day trial exists in reach | Medium | Quota unmet | Clear guidance to widen channel subscriptions; run again |
